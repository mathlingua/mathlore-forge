# Write Mathlore Prose

Load only the reference needed:

- [Narrative prose](references/narrative-prose.md): page exposition and `Text:`.
- [Documentation fields](references/documentation-fields.md): `called:`,
  `written:`, `adjective:`, `description:`, and specialized fields.
- [Rendering templates](references/rendering-templates.md): `?`, `+?`, `-?`,
  conditional fragments, and mapping `writing:` templates.
- [Code examples](references/code-examples.md): `mlg` versus `mlg-fragment`
  fences and formatter behavior.
- [Citations](references/citations.md): `References:`, resources, and page links.

Read the entire surrounding page before writing. Explain motivation or meaning;
do not merely restate the next formula. Match local terminology, notation,
capitalization, and the existing balance between prose and structured cards.
